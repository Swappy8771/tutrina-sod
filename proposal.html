Action Required

Client Responsibilities

The following items must be provided by the client for the project to stay on schedule.

Logo

PNG or SVG, high resolution. Required before Phase 2 begins.

Brand Colors

Hex codes or brand guide. Required before Phase 2 begins.

Course Details

Name, description, subjects, benefits, class info. Required for Phase 4.

Faculty Details

Name, photo, qualification, experience, expertise. Required for Phase 4.

Testimonials

Student/parent name, review text, optional photo. Required for Phase 4.

Study Materials

PDFs, notes, worksheets organized by course. Required for Phase 4.

Institute Information

History, vision, mission, achievements, values. Required for Phase 4.

Contact Details

Phone number, email, full address. Required for Phase 3.

Email for Notifications

Email address to receive form submission alerts. Required before forms go live.
